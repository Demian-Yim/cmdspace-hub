# CMDSPACE. AI가 일하게 만드는 지식 구조.

CMDSPACE는 기업의 AI가 실제 업무에 정착하도록 지식·업무 흐름·사람을 함께 설계하는 기업 AX·컨텍스트 아키텍처 전문 서비스 회사입니다. 임원 교육과 코칭으로 문제를 발견하고, 진단·파일럿·조직 확산·운영체계로 연결합니다.

## 도구와 교육을 실제 운영으로 연결합니다

AI 도입의 병목은 기능 부족보다 조직의 맥락·지식·책임이 흐려지는 데서 생깁니다. CMDSPACE는 세 영역을 하나의 설계로 묶습니다.

01 / Alignment

### 경영진과 현장을 정렬

임원 교육·코칭으로 조직의 실제 문제와 스폰서, 성공 기준을 먼저 확인합니다.

02 / Context

### 지식과 업무 흐름을 구조화

문서·회의·경험을 Context Pack과 검색 가능한 지식 구조로 전환해 AI가 일할 맥락을 만듭니다.

03 / Operations

### 책임과 품질을 운영 리듬으로

접근 권한·갱신 주기·관리자 역할·품질 기준을 문서화해 교육 뒤에도 계속 작동하게 합니다.

## 발견에서 운영까지, 다섯 단계로 연결합니다

고객의 문제·보안·데이터 성숙도에 따라 단계를 조정하며, 파일럿의 사용과 지표가 확인될 때만 확산을 권합니다.

01 Discover

### 문제 발견

임원 교육·코칭으로 우선 질문과 내부 스폰서를 확인합니다.

02 Diagnose

### 기준선 진단

지식 원천·핵심 업무·보안 조건·성공 기준을 정의합니다.

03 Pilot

### 부서 파일럿

한 부서·한 업무에 Context Pack·LLM Wiki·AI 흐름을 구축합니다.

04 Scale

### 조직 확산

수준별 핸즈온·관리자 양성·전달체계로 반복 가능성을 만듭니다.

05 Operate

### 운영 정착

책임·갱신·품질·보안·분기 감사를 운영 리듬으로 만듭니다.

### 검증된 수행 범위

고객명·경영진 실명·세부 코칭 내용은 승인 범위에 따라 비식별화합니다. 고객 내부 성과를 CMDSPACE의 성과로 재귀속하지 않습니다.

## 다루는 교육 주제

강의 제목에는 단어로 압축되지만, 실제 다루는 주제는 훨씬 넓습니다. 청중(임원·연구자·교사·학생·실무자)별로 같은 기술을 서로 다른 층위로 풀어냅니다.

01

### 생성형 AI 리터러시

언어모델 원리부터 프롬프트 엔지니어링, 유료 기능 활용, 실무 자동화까지. ChatGPT · Claude · Gemini 를 목적에 맞게 조합해 쓰는 감각을 기릅니다.

→ 일반 실무자 · 임원 · 교사 · 학생 · 학부모

02

### 연구자용 AI

논문 탐색·읽기·쓰기·인용, AI로 데이터 정제와 분석 자동화, 나만의 연구 보조 GPT 만들기. 연구 프로세스 전 단계를 LLM과 함께 재설계합니다.

→ 대학원생 · 교수 · 연구소 · 기관 연구팀

03

### 개인지식관리(PKM) · 세컨드브레인

티아고 포르테의 BASB, 루만의 제텔카스텐, kepano·닉 마일로의 LYT를 한국 실무 맥락에 맞게 재구성한 CMDS 프로세스. 옵시디언 기초부터 고급 플러그인·그래프 활용까지.

→ 지식노동자 · 연구자 · 학생 · 콘텐츠 크리에이터

04

### AI 에이전트·멀티에이전트

Claude Code · OpenClaw 기반 에이전트 구축, MCP로 외부 도구 연결, Obsidian 볼트를 에이전트의 장기 기억으로 활용. 9Yohan 멀티에이전트 오케스트레이션 사례.

→ 개발자 · Power User · 프로덕트 팀

05

### CEO · 리더십 AX 교육

그룹 임원·회장단·CEO 대상 AX 교육과 1:1 코칭. AI 시대에 조직과 본인의 의사결정을 어떻게 재설계할 것인가.

→ 사장 · 부사장 · 임원 · 대기업/공공기관 리더

06

### 데이터 분석·시각화

기초·고급 통계, 회귀·ANOVA·SEM, 머신러닝 지도·비지도학습, 토픽 모델링. Tableau로 패널데이터 스토리텔링, ESG·HR Analytics 실무 사례.

→ 연구자 · HR · 마케팅 · 정책 담당자

07

### 교수법·커리큘럼 설계

중고등 · 대학 · 기업 · 공공기관 맞춤 학습 경험 설계. 실습 중심 Day 1~3 워크샵, 시리즈 과정, 장기 코칭 프로그램 기획.

→ 교사 · 교수 · 교육 담당자 · L&D 팀

08

### 노코드·자동화
