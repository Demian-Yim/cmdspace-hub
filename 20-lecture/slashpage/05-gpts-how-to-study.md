# GPTs 어떻게 공부할까요?

## GPTs 학습 로드맵

> "전 과정을 모두 끝내야 한다는 부담은 갖지 마세요. 원하는 수준까지 차근차근 따라오면 충분합니다."

1. '만들기' 기능 맛보기
   - 버튼 몇 번으로 간단한 대화형 챗봇을 직접 만들어 보며 감을 잡아요.

2. '구성 → 지침' 으로 챗봇 다듬기
   - 짧은 명령문만으로 챗봇의 말투·목표·제한사항을 손쉽게 설정합니다.

3. '지식 → 파일 업로드' 활용
   - 내 PDF·문서·자료를 올려 두고, 그 내용을 바탕으로 맞춤형 Q&A 챗봇을 만들어 보세요.

4. 주요 기능 익히기
   - 웹 검색, 캔버스, 4o 이미지 생성, 코드 인터프리터 & 데이터 분석
   - 각 기능의 특징을 이해하고, 상황에 맞게 챗봇 능력을 확장합니다.

5. 모델 선택 감각 익히기
   - '권장 모델' 목록을 참고해 작업 목적에 맞는 모델을 고르고 써 보세요.

6. '작업 → 새 작업 만들기'로 외부 연동
   - API 호출을 통해 외부 서비스와 데이터를 주고받으며 GPTs를 업무 자동화에 활용해 봅니다.

> **Tip.** "각 단계에서 충분히 익숙해졌다는 느낌이 들면, 다음 단계로 넘아가면 됩니다. 필요 없는 단계는 과감히 건너뛰어도 무방해요."
